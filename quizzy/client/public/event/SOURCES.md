# Event artwork

- `poster.png` and `partner-logos.png`: artwork provided by the event organizer in this task. The second file is the low-resolution reference strip.
- `utc-official-logo.png`: downloaded from the [University of Transport and Communications official website](https://www.utc.edu.vn/assets/utc/images/logo.png) on 2026-11-19 to verify the first seal in the organizer's artwork.
- `utc-seal.png`: high-resolution matching UTC seal from the [UTC student programming event](https://olp.sfit.com.vn/truong.png).
- `msd-united-way.png`: high-resolution combined mark from [MSD United Way Vietnam](https://msdunitedwayvn.org/wp-content/uploads/2022/10/LOGO-1-1.png).
- `gender-equality-symbol.jpg`: the campaign symbol from the [Vietnam Government portal](https://tc.cdnchinhphu.vn/Uploaded/tranthitiep/2016_10_27/logo.jpg). CSS frames only the symbol and hides the color notes below it.
- `fonts/`: Cormorant Garamond and Great Vibes downloaded from Google Fonts; their SIL Open Font Licenses are included in this folder.

The page displays the four marks separately in the organizer's order for sharp rendering. The poster remains the supplied artwork.
